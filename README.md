# 民宿 もりもり ウェブサイト

ビルド不要の静的サイトです。HTML / CSS / JavaScript のみで作られており、
npm やフレームワーク、外部サービスは一切使っていません。画像もすべて自作の SVG です。

宿の基本情報（住所・料金・BBQの条件など）と、これから決める項目の一覧は
[基本情報.md](基本情報.md) にまとめています。

## ファイル構成

```
morimori_project/
├── index.html        トップページ
├── house.html        宿のご案内・料金（料金計算機つき）
├── bbq.html          BBQ・お食事
├── access.html       アクセス
├── contact.html      ご予約・お問い合わせ（フォーム＋よくある質問）
├── css/style.css     全ページ共通のスタイル
├── js/main.js        メニュー開閉・料金計算・フォーム検証・写真拡大
├── images/*.jpg      写真（HEICから変換したもの）
├── images/*.svg      イラスト（テキストエディタで色や形を編集できます）
│   ├── picture/      いただいた元データ。公開時はアップロード不要
│   └── _unused/      前のコンセプトで作ったイラスト。不要なら削除可
├── 基本情報.md        宿の基本情報と未確定項目の一覧
└── .claude/launch.json  ローカル確認用サーバーの設定
```

## 見る・編集する

HTML ファイルをダブルクリックすればブラウザで開けます。
ただし一部のブラウザは `file://` のままだと表示が崩れることがあるので、
確認はローカルサーバー経由が確実です。

```bash
python3 -m http.server 8765
```

起動したら http://localhost:8765 を開いてください。停止は `Ctrl + C` です。

編集後にブラウザで変わらないときは、スーパーリロード（macOS は `Cmd + Shift + R`）で
CSS / JS / 画像のキャッシュを捨ててください。

## よく編集する場所

| 変えたいもの | 場所 |
| --- | --- |
| 料金・定員（5万円・5千円・5名・8名） | `js/main.js` 冒頭の `BASE_PRICE` / `EXTRA_PER_PERSON` / `BASE_PEOPLE` / `MAX_PEOPLE`、および `house.html` の料金表 |
| 電話番号 | 各 HTML。表示用の文字列と `href="tel:09036325155"` の両方にあります |
| 住所 | 各 HTML の `<footer>`、`access.html`、`index.html` 末尾の構造化データ |
| BBQの条件 | `bbq.html` |
| 周辺の見どころ・所要時間 | `access.html`、`images/map.svg` |
| よくある質問 | `contact.html` の `#faq` |
| 写真 | `images/` の SVG を写真（jpg / webp）に置き換え、各 HTML の `src` と `alt` を変更 |

### iPhoneの写真（HEIC）をサイトで使えるようにする

HEIC はブラウザで表示できないため、JPEG に変換します。macOS 標準の `sips` だけでできます。

```bash
sips -s format jpeg -s formatOptions 72 -Z 1800 images/picture/IMG_0000.HEIC --out images/photo-名前.jpg
```

`-Z 1800` が長辺の最大ピクセル数、`formatOptions` が画質（0〜100）です。
ページの主役に使う大きな写真は長辺1600〜1800px・300KB程度、
ギャラリー用は `-Z 900` 程度が目安です。

置き換え漏れの確認にはこのコマンドが使えます。

```bash
grep -rn "090-3632-5155\|09036325155\|50,000\|岩美町大谷897-1" --include="*.html" .
```

## 料金の計算ルール

`50,000円 +（宿泊人数 − 5）× 5,000円`（5名以下は一律50,000円）を1泊あたりの料金として、
`house.html` の計算機と、予約フォームの「料金の目安」の両方で使っています。
定員は8名、未就学児は無料で人数に数えません。
ルールを変えるときは `js/main.js` 冒頭の4つの定数を直せば、両方に反映されます。
ただし `house.html` の料金表と `contact.html` の入力欄の `max` は手で直してください。

## 予約フォームについて

静的サイトのため送信サーバーがありません。「入力内容を確認する」を押すと、
入力値を検証したうえで内容をまとめ、コピー用のボタンを表示します。

**メールアドレスが決まったら**、`js/main.js` の `MAIL_TO` に設定してください。

```js
var MAIL_TO = 'info@example.jp';
```

設定すると、コピーボタンの代わりに「メールソフトで送信する」ボタンが自動で表示されます。
サーバーへ送る形にしたい場合は、同じ関数内で `fetch()` の POST に置き換えてください。

## 公開するとき

ファイルをそのままアップロードするだけで動きます（ビルド作業はありません）。

- レンタルサーバー：FTP で `index.html` 以下を公開ディレクトリにコピー
- GitHub Pages / Netlify / Cloudflare Pages：リポジトリのルートを公開ディレクトリに指定

公開前に [基本情報.md](基本情報.md) の「未確定・要確認の項目」を確認し、
サイト上で「確認中」「準備中」と書いている箇所を埋めてください。

## 動作確認済みのこと

- スマートフォン幅（〜950px）でのメニュー開閉
- スクロールに応じた各セクションの表示
- ギャラリー写真の拡大表示（Esc キーで閉じる）
- 料金計算機（5名・8名／複数泊、定員超過の警告）
- 予約フォームの必須チェック、メール形式・電話番号チェック、過去日の拒否、定員チェック、料金の目安表示
- よくある質問の開閉
